今日 / 近3天核心结论

三条主线，快速对齐
1

Anthropic 上市首日走出一条冲高回落的曲线：以 111.50 美元开盘（较 83 美元发行价高 34.3%），盘中一度冲到 114.99 美元、完全摊薄市值突破 2 万亿美元，但尾盘回落至 97.17 美元收盘，涨幅收窄到 17.07%，市值 1.27 万亿美元。昨天判断「高出区间定价是为首日留出约 20% 涨幅」基本被验证，但幅度略低于预期——首日只在盘中短暂越过 100 美元关口。前夜还有百余名学者联署「The MisAnthropic Statement」，指其一边警告递归自我改进的风险、一边争着第一个把它造出来，把估值与信任的裂缝摆到了同一天。

2

英伟达出现了基本面与股价的极端背离：第三季度营收同比翻倍至 1158 亿美元、数据中心业务增长 110%、新一代 Vera Rubin 平台单季贡献近 200 亿美元；但股价周四收于 145.98 美元、创 52 周新低，较 10 月 6 日历史高点跌近 40%。市场定价的已不是当期业绩，而是治理不确定性——CEO 更替、董事会分歧、出口管制，三者叠加把「AI 溢价」翻成了「AI 折价」。

3

算力获取正在被从两端同时收紧：美国商务部收紧 AI 芯片出口并关闭第三方国家云算力通道后，Moonshot AI 取消了与印尼云服务商的 1.5 亿美元合同（原计划租用 B300 集群训练 Kimi K4，且已预付约 50%、远超行业标准的 15%）；台积电与三星暂停向中国客户交付部分处理器、需申请许可，字节跳动、百度昆仑等在受影响名单内，非 AI 芯片豁免取消还波及小米、OPPO、vivo 的手机处理器。对国内大模型公司而言，「买不到卡」与「租不到云」同时发生，训练计划的可行性要先过合规关。

Anthropic 首日冲高回落：开盘 111.50 美元、盘中市值破 2 万亿，收盘 97.17 美元仅涨 17%

当地时间 11 月 19 日，Anthropic 以代码「ANT」在纳斯达克挂牌，开盘价 111.50 美元，较 83 美元发行价高约 34.3%，较路演区间下限 70 美元高 59.3%；盘中最高触及 114.99 美元（+38.54%），按完全摊薄约 182 亿股计算市值一度突破 2.03 万亿美元，超过 Meta、博通位列全球上市公司第六；随后震荡走低，收于 97.17 美元，较发行价上涨 17.07%，对应市值约 1.27 万亿美元。本次 IPO 公开发行募资超 810 亿美元，叠加同价私募配售，公司现金储备预计达约 2200 亿美元。招股书更新文件显示，2026 年前九个月营收 332 亿美元、同比增长约 1206%，截至 10 月底年化营收运行率约 810 亿美元。

The Decoder 报道，美国商务部收紧 AI 芯片出口管制并关闭第三方国家云算力通道后，亚洲多笔大型 AI 数据中心交易开始瓦解。Moonshot AI 取消了与印尼云服务商的 1.5 亿美元合同，原计划租用英伟达 Blackwell Ultra（B300）集群训练 Kimi K4，此前已预付约 50%、而非行业标准的 15%。台积电与三星暂停向中国客户交付部分处理器、需申请许可，字节跳动、百度昆仑等客户受影响；非 AI 芯片豁免取消亦波及小米、OPPO、vivo 等智能手机处理器供应。

上市前夜百人联署「The MisAnthropic Statement」，Anthropic 安全治理结构受审视

据潮新闻报道，Anthropic 上市前夜一份名为「The MisAnthropic Statement」的联名声明发布，签名者超过百人，包括图灵奖得主 Judea Pearl、诺贝尔经济学奖得主 Oliver Hart 以及四位菲尔兹奖得主，措辞直指 Anthropic 一边警告递归自我改进的 AI 可能「集中权力、脱离人类控制」，一边「争着第一个把它造出来」。The Verge 同日报道称，其完成史上最大规模 IPO 后，安全治理结构与权力结构正受到审视。Anthropic CEO Dario Amodei 在挂牌当日发表声明，称此次上市让公司财务地位更稳固，强调不会向商业或政治压力低头，将放慢 AI 训练与部署节奏以确保安全与人类可控，并承认滥用、经济冲击与失控等风险，倡导行业「向顶部竞赛」。

公司与产品11-19Google 官方博客 / Google DeepMind（Philipp Schmid）

Google 在 Gemini API 与 AI Studio 上线 Genie 4 实时世界模型，并推出 Tool Retrieval 预览

11 月 19 日，Google 宣布 Genie 4 世界模型在 Gemini API 与 AI Studio 上推出，可从文本或图像生成 720p、24fps 的世界，并用 WASD、提示词与 48 kHz 立体声实时操控，支持通过 WebRTC（浏览器加临时 token）或 WebSocket 串流调用。同日 Google 在 Gemini API 的 Interactions API 中以预览形式推出 Tool Retrieval，让智能体按需加载工具参数 schema，而非每次请求发送完整工具库，以减少输入 token 并在工具数量扩大时保持选择准确。

值得跟进

Genie 4 的规格（720p / 24fps / 48kHz 立体声、WASD 与提示词实时操控、WebRTC 与 WebSocket 串流）说明世界模型已经跨过「演示视频」阶段，进入可被第三方集成的 API 形态——这是环境生成类应用（仿真、训练数据、交互内容）的供给前提。Tool Retrieval 解决的则是 agent 工具规模化的现实瓶颈：不再每次请求发送完整工具库。

值得持续跟踪的观察点

为什么还要继续跟进
  • 首日的关键细节是尾盘回落：从盘中 114.99 美元到收盘 97.17 美元，意味着有相当规模的资金选择在首日兑现。这也让「20% 首日涨幅」这个发行定价的隐含目标只完成了一半——盘中最高的 +38.5% 与收盘的 +17.07% 之间，是 2026 年新股整体低迷（十大 IPO 平均低于发行价约 20%）记忆的回归。
  • 约 2200 亿美元的现金储备是这家公司未来几年最重要的战略变量。它意味着 Anthropic 可以在不依赖新一轮融资的情况下维持长期训练投入，竞争焦点会从「谁能融到钱」转向「谁能把钱花对」——但上市公司同时要面对季度业绩压力，这与「放慢节奏以确保安全」的承诺天然冲突，未来 2–3 个季度的资本开支节奏就是检验点。
  • Dario Amodei 的表态值得单独记下：不向商业或政治压力低头、放慢训练与部署节奏、倡导行业「向顶部竞赛」。这是一份写进 IPO 当日的公开承诺，比任何安全报告都更容易被后续行为对照。
  • 「The MisAnthropic Statement」的反驳逻辑（一边警告递归自我改进、一边争着第一个造出来）不会因为股价上涨而消失，反而会成为监管听证与公众质疑的标准模板。对同业而言，这意味着「安全叙事」从此需要附带行为证据。
  • 英伟达的背离有一个清晰的修复路径：如果 CEO 定案、治理调查收尾，Vera Rubin 单季近 200 亿美元的收入贡献会立刻变成最直接的估值理由；反之，若董事会内部分歧继续外溢，业绩再好也难以阻止估值下修。
  • Moonshot 预付 50%（远超行业惯例 15%）这件事，说明国内团队对算力的焦虑已经到了愿用现金锁定远期供给的程度。合同取消后有两件事值得跟踪：预付款如何处置、是否转向国产加速卡——后者会直接反映在国产芯片的订单与产能数据上。
  • 管制外溢到手机处理器（小米、OPPO、vivo）说明「非 AI 芯片豁免取消」把消费电子也纳入了同一套许可框架，这会影响明年上半年国内安卓旗舰的发布节奏与备货策略。
  • Google 一天之内在三个层面出手：桌面 agent（Mac computer use）、世界模型 API（Genie 4）、工具检索（Tool Retrieval）。三者对应同一件事——把 Gemini 从「对话产品」做成「可被集成的执行层」。这比再发一个模型更能改变开发者的选择。
  • Mac 版 Gemini 明确「屏幕和光标控制权仍归用户」，这是桌面 agent 的责任边界设计。企业采购时最先问的往往不是能力而是「能不能随时中断、有没有操作日志」，这条产品说明实际上是在回答采购问题。
  • MIT 那份研究的杀伤力在于它给出了具体归因：513 例来自 PM2.5、137 例来自烟雾，占全美电力相关死亡的 5.3%。数据中心选址今后很难只谈电价与土地，下风向人口密度会变成硬约束。
  • Ai2 的 Theorizer 与 OpenAI 的 Performance Factory 指向同一个方法论：让模型在有「可验证信号」的环节工作——文献可核查、性能可量化。这解释了为什么 agent 在科研假设与性能回归上先跑通，而在开放式决策上仍慢。
  • Perplexity Brain 的「证据足够才更新技能」是一条值得抄的纪律。它把自我改进从「每次对话都重写规则」改成「积累到可复现再固化」，对 agent 长期记忆的稳定性影响很大。
