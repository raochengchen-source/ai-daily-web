丹麦最高法院裁定：持有并传播 AI 生成儿童色情内容可判实刑

据彭博社 10/15 报道，丹麦最高法院维持对一名 31 岁男子 18 个月监禁（不适用缓刑）的判决，其因持有并传播 3.6 万余张 AI 生成的儿童色情图像获刑；法院裁定即使图像无真实人物原型也受丹麦《刑法》约束，量刑时不考虑人物是否虚构；此案为丹麦首起此类定罪，并引发跨国调查（警方查明 273 名买家身份、逮捕 25 人）。

值得持续跟踪的观察点

为什么还要继续跟进
  • 头部闭源厂商静默期：OpenAI（最近一次模型侧大动作是 10/14 停用 GPT-5.5，GPT-5.6 系列与降价在 7-8 月）、Google（Gemini API changelog 近 3 天无更新）均无窗口内高置信新发布；需关注其对 DeepSeek / Muse Spark 开源冲击的回应节奏。
  • 字节火山引擎“豆包 1.6 / 语音 2.0”等发布信息时间线存在冲突（部分来源标注为 2025 年 10 月 FORCE LINK 武汉站），本期未纳入，待官方口径确认后跟进。
  • 出口管制征求意见（10/16 起）进入窗口期：关注正式稿对“开源 / 论文公开豁免”与“出口前登记”的落地细节，直接影响大模型出海与开源合规。
  • DeepSeek 生态扩张：搜索 API 定价（1000 次 / 5 元）与 Harness / CodeBuddy / WorkBuddy 等接入案例，将检验“模型 + 工具链”闭环的商业化空间。
  • Anthropic 就业数据或成行业样板：若更多大厂公开 AI 对岗位结构的影响，“Agent 工时占比”有望成为组织健康度的新观察指标。
  • 本地推理硬件放量（RTX Spark 128GB）：端侧 70B 级模型部署成本下降，可能改变中小企业推理采购结构，与云 API 价格战形成对冲。
