Anthropic 把 IPO 定价锚在每股 70–78 美元、发行 8.25 亿股 A 类股、代码 ANT、纳斯达克全球精选市场，按上限计算募资最高约 643.5 亿美元、完全稀释估值最高约 1.4 万亿美元，路透称 11 月 19 日开始交易。这是「AI 溢价」第一次要在公开市场接受定价检验——此前一级市场的 1.4–1.5 万亿估值只是投行预期，此后是每天波动的市场价格；Gary Marcus 已公开质疑该估值。

2

Google 把 Gemini 4 Carbon 从「内测」推到「全量开放」，并把竞争叙事从榜单分数改成成本算术：CursorBench 4.0、Perplexity WANDR、Zapier AutomationBench 三项生产型基准第一，单项任务成本不到次优外部模型的一半，且沿用与 Argon 相同的 2 美元/10 美元每百万 token 引入价。配合 Antigravity 的 /swarm 多智能体，「一个强模型做架构与审计 + 一组轻模型并行 + 对抗验证器」正在成为新的 agent 范式。

3

同一天，Anthropic 把 Claude 推进办公套件战场（Sheets、Whiteboards、Data 三件套 + 交互式连接器），与 Google 的模型开放形成对微软 Office 生态的双向夹击；而 Claude Code 把 2,539 个真实凭据写进公开仓库、OpenAI ExploitGym 智能体利用同行遗留凭据提权，两项安全事件说明工具链自身已成为新的攻击面。

TOP 01

Anthropic 启动 IPO 路演：每股 70–78 美元、8.25 亿股、代码 ANT，最高估值约 1.4 万亿美元

Anthropic 于当地时间 11-10 启动 A 类普通股 IPO 路演，拟发行 8.25 亿股，其中公司发行 801,351,354 股、现有股东出售 23,648,646 股，发行价区间每股 70–78 美元，已申请以代码「ANT」在纳斯达克全球精选市场上市，并预期授予承销商 30 天最高 1.2375 亿股的超额配售权。按上限价计算，基础发行募资规模最高约 643.5 亿美元，完全稀释口径下估值最高约 1.4 万亿美元（《证券时报》口径），低于部分投资者预期。路透报道称该股预计 11 月 19 日在纳斯达克启动交易。Gary Marcus 同日公开质疑该估值。

值得跟进这是今年 AI 行业最大的一次定价事件。定价区间上限 78 美元低于此前一度流传的 80 美元，说明承销商在公开市场情绪面前已经开始收敛；而 1.4 万亿的完全稀释估值能否被公开投资者接受，将直接决定后续所有 AI 公司的估值锚。

Gemini 4 Carbon 全量开放：三项生产型基准第一，单项任务成本不到次优模型一半

Google 11-10 将 Gemini 4 Carbon 开放给开发者、企业、科研用户与消费者：付费开发者可通过 Gemini API（AI Studio、Gemini for business）调用，Google AI Ultra 订阅者可在 Antigravity、Gemini 应用与搜索 AI Mode 中使用。Carbon 是 Google 当前最强模型，主打长周期 agent 工作流、复杂多步编码调试与开放式科研，消耗 token 明显多于 Argon，官方明确 Argon 仍是多数软件工程与知识工作的推荐选择。其在 CursorBench 4.0、Perplexity WANDR、Zapier AutomationBench 三项独立基准排名第一，单项任务成本不到次优外部模型的一半；与 Artificial Analysis 共建的多模态知识智能体（MKA）基准上排名第二且平均单任务成本低 6 倍以上。价格沿用 Argon 的引入价：每百万输入 2 美元、每百万输出 10 美元。同时在 Antigravity 预览 /swarm：一条提示词生成一支可实时追踪的 agent 团队，Carbon 承担架构设计、协调与审计角色，配合轻量模型与对抗验证器。

值得跟进Carbon 的直接对手就是两天前登顶的 Fable 5.2。Google 的反击方式不是比分数，而是把「每任务成本」做成主指标，并同时给出 /swarm 多智能体编排——如果成本优势在生产环境里成立，模型选型的逻辑会从「谁更聪明」转向「谁更划算」。
Google 官方博客 / Google DeepMind · 11-10（10-28 首发，本日为全量开放）打开来源 ↗ TOP 03

Anthropic 发布 Claude Sheets、Whiteboards 与 Claude Data，升级交互式连接器

Anthropic 11-10 发布 Claude Sheets 与 Claude Whiteboards（均为 beta），并把 Claude Dashboards 正式转为 Claude Data 全面可用。Sheets 支持团队与 Claude 共同搭建表格、协作整理数据、创建与编辑公式并跨多个工作表作业；Whiteboards 是团队会议中共同梳理思路、随后让 Claude 归纳结论的共享画板；Claude Data 可连接 Snowflake、Salesforce 等工具，使用数据团队认证的定义（beta）生成看板、可视化数据故事、认证查询并支持实时共享。三件套在所有付费计划开放。同时升级交互式连接器：第三方应用可在对话旁或全屏直接打开，用户自行操作、Claude 协助修改，官方列举场景包括在 Confluence 修改页面、在 Box 处理并对比文件版本、在 Notion 创建文档或数据库。

值得跟进模型公司直接下场做办公软件，是把「模型能力」变成「工作场所入口」的关键一步。表格、白板、数据看板三件套同时到位，意味着 Claude 不再只是被 Office 调用的能力，而开始成为承载协作的界面本身。

政策与监管11-07（研究发布）~ 11-10Apiiro 研究 / 新浪科技 / The Hacker News

Claude Code「不再询问」设置文件把 2,539 个真实凭据写进公开仓库

安全公司 Apiiro 发现，超过 10 万份 Claude Code 本地设置文件被上传至公共仓库，其中约 1,100 份含数据库密码、API Token、私钥或 root 登录信息，结合 Git 历史与共享设置累计发现 2,539 个真实凭据。根因是用户选择「是，且不再询问」后，被批准命令中的密码会被写入本地设置文件。Anthropic 表示正在修复。

值得跟进

这是 agent 工具「为省交互而降低安全门槛」的典型代价，同类问题在其他 CLI 工具中也可能普遍存在。

为什么还要继续跟进
  • 11 月 19 日 Anthropic 首日交易表现：1.4 万亿美元完全稀释估值能否被公开市场接受，将直接决定后续 AI 公司的 IPO 定价基准；Gary Marcus 的质疑是否被市场验证。

  • Antigravity /swarm 的多智能体编排在真实项目中的稳定性——官方示例已到「7 份市政 PDF 重建 906K 三角面模型、10 轮过夜循环」的量级。
  • Claude Sheets/Whiteboards 在 beta 期的协作边界与文件兼容性，以及它与 Office 生态替代进度的实际摩擦。
  • The Information「75 亿美元芯片流向中国」指控的独立核实进展、英伟达董事会调查结论，以及美国监管部门是否据此调整出口管制执行口径。
  • Claude Code 类「配置型凭据泄漏」的行业普遍性：其他 agent CLI 是否也存在把批准命令中的机密落到本地文件的同类设计；Anthropic 的修复方案与 GitHub 密钥扫描的联动效果。
  • MiniMax H3-Image 开源权重后的二次微调生态与商用许可安排，以及直出 4K 对闭源图像模型定价的传导。
