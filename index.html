今日 / 近3天核心结论

三条主线，快速对齐
1

Anthropic 在 IPO 路演前把 Claude Fable 5.2 推到 Artificial Analysis Intelligence Index v5 首位（65 分，领先 Gemini 4 Carbon 5 分），同时输出速度最高提升 30%、标准输入输出价格均下调 20%——顶级能力与降价并行，这轮竞争已从「参数规模」转向「能力上限 + 单位成本」的正面挤压。

2

芯片主战场从「峰值算力」转向「工作负载专用化」：Google 一年内首次推出四款 TPU，新增的 8tx 主打硬件级机密推理（政府与金融等受监管行业可在同一机密系统内完成微调、蒸馏与强化学习），8i Max 专攻超长上下文与更高机架密度。这与近期中国移动千亿算力、北美 CSP 开支加速形成同一趋势的两端。

3

国内两条线同日推进，且都瞄准「生产环节」而非单次生成：字节 Seedream 5.5 用「非编辑区像素级保持 + 最多 100 轮连续编辑 + 原生 RGBA 透明输出」改写内容生产工作流；百度 ERNIE Evolve 把研究方向选择与实验迭代交给多角色协作的自动研究系统。

TOP 01

Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2，登顶 Artificial Analysis 智能指数

Anthropic 于当地时间 11-09 发布 Claude Fable 5.2 与 Claude Mythos 5.2，两者为同一底层模型，Mythos 需通过 Cyber 或 Life Sciences Verification Program 申请访问，定位于高难度技术工作。Artificial Analysis 评测其在 Intelligence Index v5 取得 65 分登顶，领先 Gemini 4 Carbon（high, 60）5 分、Claude Opus 5.5（max, 59）6 分。官方称相较上一代输出速度最高提升 30%，标准输入与输出价格均下调 20%；并披露一个早期版本 Fable 5.2 的智能体团队把关键生产服务从 Python 迁至 Rust，启动速度提升约 26 倍。发布时点多在 IPO 路演筹备期。

值得跟进这是 IPO 冲刺前夜的最强模型发布：65 分把 Gemini 4 Carbon（60）压到第二，且同步降价 20%、提速 30%。对 Anthropic 而言，它同时是估值谈判的技术筹码和「最强模型」叙事；对竞对而言，压力从能力层面直接传导到价格层面。

Google 发布 TPU 8tx 与 8i Max：一年四款，为「智能体时代」做专用化

Google 11-09 宣布扩充第八代 TPU 阵容，新增 TPU 8tx 与 TPU 8i Max：TPU 8tx 提供硬件级安全，面向敏感数据与机密推理（政府及金融等受监管行业可在同一机密系统上完成微调、蒸馏与强化学习，无需在集群间搬运敏感数据），并兼顾小规模训练；TPU 8i Max 面向超大上下文窗口与更高机架密度。二者与 TPU 8t、8i 共同构成第八代产品线，2026 年成为 Google 首次在一年内推出四款 TPU 的年份。

值得跟进TPU 过去约两年一代，今年已连发四款，且不再单纯比拼算力，而是按 agent 生命周期切分专用能力。这是 Google 用自研芯片挑战英伟达主导地位的最直接动作，也预示推理侧采购将按「安全」与「上下文规模」两条需求分流。

字节发布 Seedream 5.5：百轮编辑稳定、原生 RGBA 透明输出

字节 Seed 团队发布图像创作模型 Seedream 5.5，三项核心升级：一是更稳定的多轮编辑，实现非编辑区域像素级保持、消除色彩偏移，支持围绕同一作品多达 100 轮持续创作；二是原生 RGBA 透明素材生成，直接输出带 Alpha 通道的透明或半透明图像并精细处理轮廓边缘，省去后期抠图；三是提升光照材质与皮肤纹理真实感，并显著增强小字与复杂内容渲染。目前豆包、豆包工作、即梦已接入，API 即将上线。

值得跟进它改的是内容生产的返工成本：非编辑区域像素级保持 + 100 轮连续编辑，意味着同一张图可以被反复修改而不掉画质；原生透明素材直接省掉抠图环节。对电商、直播物料、设计外包这类高频改图场景，这是工作流级别的变化。

Meta 发布 Muse Ember：跑分追平 Claude Haiku 5.5，单任务成本约为其三分之一

Meta 11-09 发布其最小、最高效模型 Muse Ember（muse-ember-1.0），面向工具调用、编码子任务、路由、抽取与长文档解析等智能体日常重复任务。第三方评测 Artificial Analysis 综合智能指数 36 分，与 Claude Haiku 5.5 最高推理档持平，但单任务成本约为其三分之一。同日通过 Muse Code 与 Meta Model API 上线，定价 0.10 美元/百万输入 token、0.50 美元/百万输出 token。

值得持续跟踪的观察点

为什么还要继续跟进
  • Fable 5.2 的能力声明（8 天做操作系统、30 小时费马证明）在第三方独立复现中的表现，以及 Mythos 5.2 的受限访问机制会否阻碍外部安全研究。

  • Seedream 5.5 的 API 上线时间与正式定价，以及 100 轮编辑在真实电商/直播物料链路中的稳定性。
  • 黄仁勋独立调查结论、国会相关委员会的动作，以及出口管制政策是否因此转向更严。
  • Muse Ember 类「跑分持平、成本 1/3」小模型普及后，agent 产品的定价与毛利结构如何变化。
  • 1000 智能体复现数学证明的可复现性与验证器依赖程度——这决定多智能体在科研场景的可信上限。
