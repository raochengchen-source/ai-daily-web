Mistral 开放 Large 4（Le Chonk）完整权重：1T 参数 MoE、1M 上下文、修改版 MIT

Mistral AI 于当地时间 10 月 29 日开放旗舰模型 Mistral Large 4（代号 Le Chonk）完整权重，托管于 Hugging Face（mistralai/Mistral-Large-4-1T-A52B，FP8/NVFP4 格式），并在自有 API 与合作伙伴平台提供；模型约 1T 总参数、激活约 49-52B（MoE），1M token 上下文，原生多模态（文本/图像输入，文本/代码输出），采用修改版 MIT 的 Mistral Ecosystem Open-Weight 许可；距离 10 月 6 日 API 预览约三周。Unsloth 同日发布其 1-bit GGUF 量化版。

值得跟进这是迄今欧洲厂商开放的规模最大的旗舰级开源权重：1T 参数 + 约 50B 激活的 MoE 架构、1M token 上下文、原生多模态，配合社区量化已可本地运行——开源权重旗舰直接对标闭源前沿模型，是全球开源生态的标志性事件。

Anthropic 研究模型自主发现并串联五大平台漏洞：Chrome 62 个 CVE、锁屏提取照片、53 分钟 Linux 提权

Anthropic 于 10 月 27 日发布研究报告：其未公开的 Claude 研究模型在 Chrome、Safari、Android、Windows、Linux 五个平台发现并串联出 5 条可运行的攻击链。Chrome 方面向谷歌提交的报告共产生 62 个严重或高危 CVE（含 13 个沙箱逃逸、21 个可控制网页渲染进程的漏洞），修复已随 Chrome 156 发布；Safari 漏洞可绕过同源策略窃取登录数据；Android 可在锁屏状态下提取照片；Linux 在 53 分钟内获取最高权限；Windows 涉及 QUIC/HTTP3 内核漏洞（CVE-2026-33096）。10 月 28-29 日国内外媒体密集报道。

值得跟进Anthropic 用未公开的内部研究模型完成从漏洞发现到攻击链串联的全流程：仅 Chrome 就产生 62 个严重/高危 CVE（含 13 个沙箱逃逸），Android 锁屏下可提取照片、Linux 53 分钟获取最高权限——展示出 AI 在真实世界攻防中的能力上限，直接冲击安全行业对 AI 红队的认知。

OpenAI 发布新版 Model Spec：围绕五项核心价值观重组模型行为准则

OpenAI 于 10 月 29 日发布新版 Model Spec（模型规范）：在收集公开反馈、部署经验与外部专家讨论后，将准则围绕五项根本价值重组——对人类意图的忠诚、危害最小化、诚实与透明、人类主体性、关怀；明确拥抱「知识自由」（模型应赋能人们在有争议话题上探索、辩论与创作，不受任意限制）。同日 OpenAI 还发布《How we detect frontier model misalignment》技术博客，介绍其扩展至训练/评估/内部使用/外部部署全表面的失准监控系统。

值得跟进Model Spec 是 OpenAI 模型行为对齐的顶层规范文件：本次更新首次以「对人类意图的忠诚、危害最小化、诚实与透明、人类主体性、关怀」五项核心价值观重组全部准则，并明确拥抱知识自由——为模型行为治理提供了新的结构框架，也是各厂商对齐规范的标杆性文本。
