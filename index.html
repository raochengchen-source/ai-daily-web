Google Antigravity 2.29 上线语音模式：基于 Gemini Live 直接听声、改代码、批权限

Google 的智能体开发平台 Antigravity 在 2.29 版本加入语音模式：底层用 Gemini Live 直接处理语音而非转写文本，开发者可在空消息框、CLI 输入 /voice live 或按 F6 启动，用语音制定计划、下达代码修改指令、批准权限；支持多语言、可随时打断，智能体默认安静工作、按需每约 30 秒口述进度。

值得跟进

编程智能体的输入通道从键盘扩到语音，且支持「约 30 秒一次口头播报进度」，意味着开发者可以离开屏幕监督长任务——这是 agent 交互形态的一次实质变化。

政策与监管11-07 ~ 11-09Apiiro 研究 / Cyber Security News / iTnews / The Hacker News

安全公司 Apiiro：Claude Code「不再询问」会把密码明文写进配置，1994 个公开仓库泄露 2539 个密钥

Apiiro 研究发现，Claude Code 的「Yes, and don't ask again」选项会把通过批准的 shell 命令连同密码一起写入 .claude/settings.local.json。扫描公开 GitHub 仓库：1122 个仓库的该文件至少含 1 个真实密钥（1379 个不同值）；放宽到 git 历史后为 1994 个仓库、2539 个密钥（另在 509 个仓库的历史中多出 734 个）。泄露内容涵盖数据库密码、云密钥、API token 与 SSH root 登录。

值得跟进

AI 编程工具的「减少打断」便利设计直接转化为凭证泄露面——agent 权限管理与密钥治理将成为企业采用的前置条件。
