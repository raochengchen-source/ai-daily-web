Cartesia 发布《From Tokens to Bytes》系列研究：H-Net 字节级层级网络的扩缩优势

Cartesia 于 10 月 28 日发布「From Tokens to Bytes」系列首篇，系统论述其免 tokenizer 的层级网络 H-Net 的扩缩律：H-Net 直接从原始字节学习、以动态分块替代 BPE，在数据效率与计算效率上优于同规模 BPE Transformer；该架构此前研究显示在中英、代码与 DNA 等弱分词域提升显著（DNA 域数据效率较基线最高提升近 4 倍）。本系列为对既有成果（arXiv:2507.07955，ICLR 2026）的扩展解读与新实验。

值得跟进

免 tokenizer 的字节级架构若验证成立，将动摇以 BPE 为核心的基础设施范式，值得长期跟踪。

值得持续跟踪的观察点

为什么还要继续跟进
  • 前沿模型更替周期显著缩短：Gemini 4 Argon（9 月底）→ Genie 4（10-27）→ Gemini 4 Carbon（10-28），谷歌一周内两款发布；OpenAI 侧 GPT-6.1 Terra 与 Oracle 合作同日推进——头部厂商的发布节奏与生态动作都在加速，需跟踪「模型迭代过快」对价格与 API 稳定性的影响。
  • Alphabet Q3 的关键信号：Cloud 增速 103%（上季 82%）说明 AI 需求仍在放量，但自由现金流转负 + 明年资本开支大增构成回报检验点；Gemini 月活 10 亿是消费者侧的重要里程碑，商业化路径（订阅/API/广告）未见披露细节。
  • Cathedral 渗透事件：Anthropic 官方称「部分销售/HR/IT 系统、范围有限」，Cathedral 报告称触达更广（含会议纪要、薪资、Offer），双方说法不一；事件暴露第三方商业软件成为 AI 渗透的软肋，AI 攻防研究的披露规则（先通报后发布）成为讨论点。
  • GitHub 数据是开发者侧最强信号：超 40% PR 由智能体起草意味着「人审机器代码」成为主流工作流，Agentic Workflows GA 与自带智能体支持进一步模糊 Copilot 与其他 coding agent 的边界。
  • 端侧/免 tokenizer/OCR 三条技术线同周发声（MiniCPM-OCR、H-Net、Liquid LFM3 为昨日），小模型与架构创新在持续分流「更大参数」叙事。
