三条主线，快速对齐
1

黎曼猜想在一天之内出现两份互不相让的声明：Anthropic 数学家 Alpöge 称与 Claude 合作完成证明，公开的却是约 1700 万行 Lean 代码、人类可读版估计超过 25 万页，本人承认尚未掌握全部数学内容；几小时后，美国数学学会会长 Ravi Vakil 公开斯坦福年轻数学家 Masullo 一份纯人类、940 页的证明。两份都没完成独立验证，Anthropic 也未为前者背书。「AI 能否做数学」由此从假设变成程序性问题：可验证性、可读性、成果归属，以及厂商口径的一致性（Anthropic 三个月前官方研究明确称不指望相关技术证明黎曼猜想）。

2

市场用两天时间给出对 AI 估值的裁决：创纪录的 IPO 没能托住股价。Anthropic 上市次日收 88.91 美元、跌 8.50%，盘中最低 83.05 美元、距发行价仅 5 美分，完全摊薄估值约 1.6 万亿美元；同日纳指收跌 5.28%、费城半导体指数 -10.73%、英伟达 -14.01% 并连续七个交易日下跌，日经 -4.6%、软银 -15%。争论焦点从「AI 需求是否真实」切换到「融资能否转化为匹配估值的回报」。

3

供给端两条路线同日加速：腾讯把 770B 旗舰 Hy4 的权重全量开放（Apache 2.0、四平台同步、附 System Card），混元 LLM 系列至此全部开源；Thinking Machines 用循环 Transformer 把 26.4B 总参、3.4B 激活的 Inkling 2 Mini 做到笔记本本地可跑。开源竞争的重心从「参数规模」转向「单位算力换来的有效推理」，同时把安全评估卡片变成了发布标配。

Thinking Machines 发布 Inkling 2 Mini：26.4B 总参、笔记本可跑的开源权重模型

Thinking Machines Lab 发布开源权重模型 Inkling 2 Mini，Apache 2.0 许可。24 层 decoder-only MoE，总参 26.4B、激活 3.4B，中间 12 层每 token 运行三次（共 48 次层应用），有效激活参数 5.4B；原生多模态，支持 1M 上下文，权重以 NVFP4/MXFP8 混合精度发布，另附 DSpark 草稿模型。官方称在 DeepSWE v1.1 达 48.2%、Vals Index v2.2 达 46.5%，领先所有总参低于 100B 的开源模型；Artificial Analysis 智能指数约 20.1，可在 32GB 以上内存的 Mac 本地运行。首日支持 SGLang、vLLM、llama.cpp、MLX 等推理栈。

值得跟进

循环 Transformer 把中间 12 层每 token 复用三次，用 3.4B 激活换到接近更大模型的效果，是「小模型 + 更多计算步」这条路线少见的开源实证；对本地智能体、私有部署的选型有直接参考价值。

OpenAI 发布反蒸馏报告：Astra 思维链提取成功率 54% 降至 0.2%，每周封禁数千至数万账号

OpenAI 于 11 月 20 日发布《Combatting adversarial distillation》。内部自适应黑盒红队测试显示，攻击者从先前请求中恢复受保护推理的平均成功率从 GPT-6 Astra 的 54.0% 降至 GPT-6.2 Astra 的 0.2%，针对当前请求则从 22.9% 降至 0.9%。防护分两层：请求层用对抗训练、输入/输出分类器（覆盖工具调用参数）与 API 级限制（推理内容与产生它的对话历史绑定，历史被改写即丢弃后续推理）；战役层追踪账号网络并执法，每周处置规模从数千到数万个账号，今夏起明显增加，并与其他模型厂商共享攻击指标。报告重申 2 月已就 DeepSeek 蒸馏向国会作简报、9 月将部分活动归因于 Moonshot AI 相关人员，并表态支持三项相关立法。

值得持续跟踪的观察点

为什么还要继续跟进
  • 黎曼两份声明的验证进度是接下来最重要的观察点：Claude 版是否有人完整跑通 Lean 编译并公开复核结论，Masullo 版修订稿何时定稿。任何一方被证伪，都会直接影响市场对「AI 前沿能力宣称」的折价方式。
  • Alpöge 声明与 Anthropic 自身口径存在落差：公司 8 月官方研究称 Claude 把满足黎曼猜想的零点比例下界从 41.6% 提升至 67.2%，并明确表示「不期待这些技术能证明黎曼猜想」。今日声明未获公司背书，且作者承认部分技术描述来自 Claude 生成的总结，需观察 Anthropic 是否给出正式立场。
  • Anthropic 股价是否守住 83 美元发行价：次日盘中仅差 5 美分，若跌破，将成为「AI 一级市场定价失效」的标志性事件，并传导至后续 AI 公司 IPO 定价与承销策略。
  • 英伟达已连续七个交易日下跌、较 10 月高点回撤近四成，但 Q3 营收仍同比翻倍。基本面与估值的背离如果继续扩大，下一轮财报的电话会议指引会比数字本身更关键。
  • 费城半导体指数单日 -10.73% 是供应链层面的信号：若存储（美光、SanDisk）与设备（Advantest、东京电子）继续同步下挫，AI 数据中心的资本开支排期可能出现实际延后。
  • 混元开源后本地部署的实际门槛值得实测：770B 总参即使 49B 激活，也需要多卡集群；真正能落地的可能是 Hy4 flash（224B 总参、含 64B Engram、每 token 激活 12B）。
  • 姚顺雨在 AMA 中称 Hy4 处于「AGI 2.5 级」、Hy4 flash 单任务成本为 Hy4 的 1/20，属厂商自评口径，需等第三方复现成本与效果。
  • Inkling 2 Mini 的循环架构把「推理步数」变成可调参数（1/3/5 次），同权重可变算力——这类设计如果被更多开源模型采用，会改变端侧与私有部署的性价比曲线。
  • OpenAI 的反蒸馏报告把推理轨迹（CoT）正式定义为需要保护的安全资产，且指出「用完整推理轨迹训练的学生模型，网络能力迁移更强」。这会让 API 供应商对 reasoning 输出的开放程度普遍收紧。
  • 欧盟委员会攻击的归因尚未公开，ARTEX 只是媒体指向的疑似工具。若后续确认，将是「商用 AI 安全工具被武器化」的第一个政府级案例，并推动欧盟在 AI 法案下补充攻防条款。
  • MiniMax MIM 的密码分析结论依赖厂商自述与自建 PoC，密码学界对「实用攻击」的门槛认定很严，需等待独立复现；但 CryptanalysisBench 由 ETH Zurich、Anthropic 等多方共建，评估框架本身具备一定公信力。
  • ChatGPT Space 把产物长期驻留在产品内，竞争对象从「模型能力」转向「工作区粘性」。若页面与幻灯片能绑定 Slack 等连接器自动更新，Google Docs / Notion 的边界会被重新划定。
